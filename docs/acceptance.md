## 저장 계약

- 키: `bugDodger_v2`, version 2.
- 기본값: 최고 기록 0초, 성공/완료 0회, 속도 1.0, 움직임 감소 false(단 OS 설정 우선), 기록 빈 배열.
- 새 판 초기화: 상태 playing, elapsed 0, x 222, 버그 0, 회피 0, 입력 0, 생성 누적 0.
- 보존: 최고 기록, 성공/완료 횟수, 다음 판 속도, 효과 선택, 최근 200판.
- 기록 200판 초과 시 오래된 기록부터 제거합니다. 필요한 실험 기록은 JSON으로 내보내세요.
- 전체 저장값이 손상되면 일부만 추측해서 복원하지 않고 선언한 기본값을 적용합니다.
- 원래 v1의 `bugDodger_best_v1` 저장값과 별개의 v2 저장 형식입니다.

## 검사 범위와 한계

- 단위 검사는 상태 모델과 저장 검증을 검사합니다.
- 기능 브라우저 검사는 Chromium과 가상 시간으로 수행합니다. 가상 시간 검사를 10분 실시간 검사로 표현하지 않습니다.
- 실시간 검사는 `soak.json`에 실제 경과 시간과 최종 조작 결과를 남깁니다.
- 자동 파일럿 20판 및 UI 기록 검사 20판은 학생의 직접 플레이가 아닙니다. 제공된 C18~C21은 플레이 기록과 비교를 요구하지만 사람 플레이 여부를 명시하지 않았습니다. 평가자가 사람 플레이를 요구하면 PLAY LAB에서 직접 같은 절차를 수행할 수 있습니다.
- 판단 이유 입력은 내보내기에 포함되며 브라우저 재접속으로 보존하지 않습니다. 기록 파일을 저장하세요.
- 공개 배포 C01과 최종 승인 여부는 로컬 테스트만으로 보증할 수 없습니다.
