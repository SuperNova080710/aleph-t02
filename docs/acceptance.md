## 검사 해석

- 단위 검사와 가상 시간 브라우저 검사를 실제 10분 실행으로 표현하지 않습니다.
- 자동 파일럿/UI 20판을 학생 직접 플레이라고 표현하지 않습니다. HTML은 사람 여부를 명시하지 않지만 필요하면 RUN LAB에서 직접 같은 절차를 수행할 수 있습니다.
- 10분 검사 JSON은 실행 시점 소스 SHA-256을 포함합니다.
- 수집/실패에 영향을 주는 핵심 동작은 움직임 감소 시에도 유지됩니다. 제거되는 것은 비필수 연출입니다.
- 대시 재충전 중 Space 입력은 입력수에 기록되지만 대시가 발동되지 않습니다. C12의 핵심 입력 검사는 좌우 레인 이동으로 정의합니다.
- 브라우저의 폰트 모양은 OS에 따라 다를 수 있습니다. 외부 폰트 요청 없이 시스템 폰트를 사용합니다.
