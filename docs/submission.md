## 재현·통과 확인 4가지

1. **어디로 가나요:** 공개 게임 주소를 열어 중앙 게임 영역으로 이동합니다. 규칙·키보드 조작·현재 상태가 같은 화면에 표시됩니다.
2. **무엇을 하나요(3단계):** ① 게임 시작 ② ←/→ 또는 A/D로 버그를 피하며 P로 정지·재개 ③ 성공 또는 실패 뒤 다시 시작합니다.
3. **무엇이 보이면 통과인가요:** 입력마다 한 칸 이동하고, 30초 생존하면 성공·충돌하면 실패가 표시됩니다. 정지 중 시간과 버그가 멈추고, 다시 시작하면 현재 판이 초기화되며 최고 기록은 새로고침 후 유지됩니다.
4. **안 될 때 무엇이 보이나요:** 저장값이 손상되면 복구 안내와 기본 기록 0초가 표시됩니다. 저장을 차단하면 탭 안에서만 유지된다는 안내가 나옵니다. 창 이탈 시 일시정지 안내가 나오며 직접 재개합니다. 이와 달리 화면 정지·중복 입력·콘솔 오류가 발생하면 검증 실패로 보고 브라우저/재현 행동을 확인합니다.
