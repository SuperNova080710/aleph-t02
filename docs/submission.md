## 재현·통과 확인 4가지

1. **어디로 가나요:** 공개 게임 주소의 NEON AFTERBURN 화면으로 이동합니다. 시작 버튼 아래에 레인 이동·대시·성공/실패 규칙이 표시됩니다.
2. **무엇을 하나요(3단계):** ① 질주 시작 ② ←/→ 또는 A/D로 코어를 모으고 Space로 장벽을 돌파 ③ 30초 완주 또는 실드 소진 후 같은 코스 재도전을 누릅니다.
3. **무엇이 보이면 통과인가요:** 입력마다 레인이 이동하고, 코어·콤보·점수가 반영됩니다. 대시 중 장벽은 파괴되며, 30초 완주 성공/실드3개 소진 실패가 표시됩니다. 재도전하면 현재 판은 초기화되고 최고 점수는 새로고침 후 유지됩니다.
4. **안 될 때 무엇이 보이나요:** 창 이탈 시 일시정지 안내가 나오며 직접 재개합니다. 손상된 저장은 기본값 복구 안내, 저장 접근 차단은 현재 탭에서만 유지된다는 안내가 표시됩니다. 그 외 입력 중복·화면 정지·콘솔 오류는 실패로 판단하고 재현 환경을 확인합니다.

## AI와 나의 판단 3줄 — 제출 전 확인할 초안

1. **AI에게 맡긴 일:** 3레인 러너의 규칙·네온 화면·대시·콤보·소리·저장·비교 기록 구현과 자동 검증을 맡겼습니다.
2. **직접 판단한 일:** 이전 버그 피하기의 품질과 재미가 부족하다고 판단하고, 장르에 얽매이지 않고 더 재미있는 게임으로 다시 만들되 과제 조건을 유지하도록 요청했습니다.
3. **AI 제안을 따르지 않은 일:** 이전 버그 피하기 개선안을 최종 결과로 받아들이지 않고 재제작을 요청했습니다. 새 버전의 재미와 제출 여부는 직접 플레이한 뒤 판단합니다.

마지막 문장은 실제 플레이를 마친 후 본인의 최종 판단으로 수정하세요. 자동 플레이를 직접 플레이로 표현하지 마세요.
